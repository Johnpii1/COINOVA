# 🪙 Coinova

> A modern crypto platform designed to make exploring digital assets simple and accessible.

## 🚀 About

**Coinova** is a modern cryptocurrency website built with a clean and responsive interface.  
The project focuses on creating a simple and user-friendly experience for exploring crypto assets.

## ✨ Features

- 🏠 Modern landing page
- 📊 Crypto market section
- 💰 Buy & Sell interface
- 🌐 Responsive design
- 🌓 Dark/Light mode
- 📱 Mobile-friendly layout
- ⚡ Fast and interactive UI
- 🎨 Modern Web3-inspired design

## 🛠️ Built With

- **React.js**
- **Tailwind CSS**
- **React Router**
- **React Icons**
- **JavaScript**
